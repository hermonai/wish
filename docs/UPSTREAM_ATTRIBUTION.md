## Wish Rebrand Boundary

Wish is a pure Warp-derived rebrand and Hermon AI alignment project in this phase. The current scope is product identity, WishUI crate naming, documentation, and buildable rename work.

Out of scope for this repository phase:

- 3D scene views
- spatial UI systems
- `wishui-3d`
- Storm or Finalverse product code

Storm is a separate future 3D/spatial product line and is not part of this Wish rebrand.
